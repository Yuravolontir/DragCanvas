# Home — landing page sections

The sections of the public landing page (`src/LandingPage.jsx`).

Deliberately **not** `src/editor/Landing/`. That directory is the editor's
element library - the Craft.js user components (Container, Text, Image,
Carousel, Map, Toolbox, Viewport) that a person drags onto their canvas. The two
have nothing to do with each other, and one letter of difference between the
names would be a trap for whoever reads this next.

- `fixtures/` - layouts produced by the real AI generator, replayed by the hero.
